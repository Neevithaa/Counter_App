# 🔢 Counter Application (React)

## 📌 Overview
The Counter Application is a simple React app that allows users to increment, decrement, and reset a counter value. It demonstrates how to manage component state using React’s `useState` hook and how to update the UI dynamically based on user interactions.

The application also includes conditional rendering to display a warning message when the counter reaches its minimum value.

---

## 🎯 Features
- Increment counter value by 1
- Decrement counter value by 1
- Reset counter to zero
- Prevents counter value from going below zero
- Displays a warning message when the minimum limit is reached
- Instant UI updates using React state
- Clean and simple user interface

---

## 🛠️ Technologies Used
- React
- JavaScript (ES6)
- CSS
